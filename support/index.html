Frequently asked questions

Does Gratuvia send my tip slips to the cloud for OCR?

The current local-first core is designed to perform private OCR on the device. Original tip-slip records are kept locally unless you intentionally export or share them.

What should I do if OCR reads an amount incorrectly?

Review the suggested fields before confirming them. OCR is an entry aid, not an authoritative source. If a slip repeatedly fails, include the document type and a description of the error in a support request; only attach the image if you are comfortable doing so.

Are paycheck and tax amounts guaranteed?

No. Gratuvia estimates pay using the information you provide. Always compare important amounts with your official pay stub, employer records, and qualified tax or payroll guidance when needed.

Where is my Gratuvia data stored?

Core records in the current mobile architecture are stored locally on the device in encrypted app storage. See our Privacy & Security page for more detail.

How do I back up my data?

Gratuvia is designed to support encrypted portable backups that you can save to a location you control. Keep the separate recovery key safe; without it, an encrypted backup may be unrecoverable.

How do I delete my data?

Local records can be removed using available app controls. Removing the app may also remove local app data, subject to device backup behavior. Exported backup files must be deleted from wherever you chose to store them. The current core app does not require account creation.

Is Gratuvia available on iPhone?

iOS is planned. The Android beta is being prepared first so the core workflow can be tested and stabilized before broader release.
