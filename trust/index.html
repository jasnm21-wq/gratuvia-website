Privacy & Security

The phone holds the core record.

Gratuvia's current mobile architecture keeps shifts, tips, schedules, payroll settings, OCR reviews, and original tip-slip records on the device. Those core features do not depend on a company server or cloud OCR service.

Local-first records

Core earnings, schedules, payroll settings, OCR reviews, and tip-slip records work from local device storage without a network connection.

On-device OCR

The current Android build uses a private native OCR module with models bundled into the app. Recognition runs on the phone.

SQLCipher database

Core structured records are stored in a SQLCipher-protected SQLite database. The database key is generated on the device and kept in platform secure storage.

Original tip slips

Gratuvia keeps the original selected or captured tip-slip image separately. OCR can create temporary working images without rewriting the original file.

SHA-256 integrity checks

Original tip-slip files are hashed with SHA-256. Gratuvia can use that hash to verify an imported or restored file against the saved record.

AES-256-GCM backups

Portable backups are encrypted on the device with AES-256-GCM. The recovery key is kept separate from the backup file.

Local-first storage

Local-first means the app can do its main job without sending every record to a remote database. You can track shifts, tips, wages, schedules, payroll settings, OCR reviews, and original tip slips from the phone itself.

That control comes with responsibility. If the only copy of a record is on one phone and that phone is lost or erased, Prokvik cannot recover a copy it never received. The encrypted backup feature exists so you can keep another copy in a location you choose.

OCR review before saving

OCR does not write directly into your earnings history as a trusted fact. The OCR engine reads the image, the parser finds likely fields, and Gratuvia shows the result for review.

Supported templates can use targeted recognition passes for fields such as tip amounts. The original image remains separate from those working copies.

Optional online services

Gratuvia may add optional account, sync, or backup services later. Those services are not required for the current core tracking workflow.

If a future feature sends personal data to Prokvik or another service provider, the Privacy Policy and the related in-app disclosure will be updated before that feature depends on the new processing.

Security claims

No app can promise perfect security. Gratuvia does not claim to be unhackable. We also will not call the system zero-knowledge or end-to-end encrypted unless the implementation and a security review support those exact terms.

Security reports

If you find a security or privacy issue, email admin@prokvik.com. Do not include sensitive user records unless the records are needed to explain the problem.
